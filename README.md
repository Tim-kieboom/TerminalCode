# TerminalCode

A lightweight, keyboard-driven IDE for the terminal, built with Rust and [Ratatui](https://ratatui.rs).

![TerminalCode editing its own source, with the explorer on the left and an integrated terminal below](screenshots/screenshot_1.jpg)

*The background picture comes from the terminal emulator, not from TerminalCode.*

## Status

**Work in progress. TerminalCode is not ready to use yet.** There are no releases and no install instructions.
The path to 0.1.0 is tracked in [docs/todo.md](docs/todo.md) and the design in [docs/design.md](docs/design.md).

A full README (install, keybinds, config) and a license will arrive with 0.1.0.
