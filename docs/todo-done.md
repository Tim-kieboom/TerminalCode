## Long single lines of ASCII
- [x] A line of plain ASCII needs no walk: `Buffer::line_len`, `position_to_byte` and `byte_to_position` use the byte length when the line is ASCII, and `text_layout` (`display_column`, `column_at_display`, `visible_cells`) and the syntax colours (`LineColors`) use byte offsets when it is printable ASCII without a tab.
